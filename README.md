# The Dante’s Space
Космический мод для Minecraft 26.1.2 / Fabric Loader 0.20.1 / Fabric API 0.155.3+26.1.2 / Java 25. Запуск клиента — `./gradlew runClient`.

## Первый рейс
1. Открой вкладку The Dante’s Space в креативе, введи `/space kit` или скрафти площадку и «Скат» по книге рецептов.
2. Нажми площадкой по блоку в месте будущего центра. Она срежет склон, деревья и другие препятствия по контуру палубы до пяти блоков над настилом. Палуба занимает 27 × 29 блоков. Поставь «Скат» на центральный магнит. Его нос направлен на север, вход между двигателями с юга.
3. Зайди через корму, пройди до пульта под передним окном и присядь. Через три секунды игроки в каюте окажутся на орбите Веспера. Для быстрого перехода из обычного мира есть команда `/space launch`.
4. Присядь у орбитального пульта для тяги. Мышь задаёт курс, V меняет дистанцию камеры. Отойди от пульта, чтобы пройтись, сохранив курс. Чтобы затормозить, присядь в двух блоках за пультом.
5. После остановки присядь у кормовой двери для выхода. Внутри корабля команда `/space home` возвращает на поверхность. Команды требуют читов или прав оператора.

Орбитальный корпус остаётся на месте во время полёта, а небесные тела перемещаются относительно него. Стартовая система фиксирована. Планеты декоративные.
