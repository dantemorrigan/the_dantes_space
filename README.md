# The Dante’s Space
Экспериментальный мод для Minecraft 26.1.2, Fabric Loader 0.20.1, Fabric API 0.155.3+26.1.2 и Java 25. Сборка — `./gradlew build`.

Скрафти площадку и «Скат» по книге рецептов. Используй площадку в свободном месте, затем установи корабль на центральный магнит. Игроки в радиусе 12 блоков отправятся на борт. Внутри есть панорамные окна, бочка, верстак и печь. Присядь перед пультом в носу для старта, смотри в направлении полёта. Отойди от пульта, чтобы сохранить курс. Для остановки присядь в трёх блоках за пультом. Для шлюза присядь в корме перед дверью после остановки. Для возвращения на площадку присядь по центру прохода за четыре блока до кормовой двери.

Прототип использует неподвижную палубу и движение небесных тел относительно неё. Небесные тела пока декоративные. Для каждого нового запуска создаётся отдельная каюта.
У штурвала включается внешний вид. V циклически меняет дистанцию камеры. Клавишу можно переназначить.
